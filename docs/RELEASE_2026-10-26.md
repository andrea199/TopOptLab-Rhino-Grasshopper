## Course material

Every platform ZIP contains the same English teaching material:

- The single HTML manual with 33 component explanations and native component images.
- Eight sequential lessons, 56 HTML lesson slides, teacher guides and student worksheets.
- A component and port introduction, illustrated installation instructions and 18 wiring walkthrough images.
- Twenty general GH/GHX examples, the roof-rib example with five load cases and 11 progressive course definitions. GH and GHX are alternative formats of the same definitions.
- Integration source, the unchanged upstream snapshot, licences and notices, and the matching offline CPU installer.

PowerPoint files are excluded from the repository and all three release ZIPs.
Instructor presentations are distributed separately. The HTML manual, illustrated
installation, 56 HTML lesson slides and exercise files remain included.

After extraction, open `START_HERE.html`, then **Open the complete English manual**.
The [installation guide](INSTALLATION.md) distinguishes the offline classroom
packages from the Windows source installer.

## Version and validation scope

The frozen course packages use integration base commit
`a067908916b9659d94284e0698b2319650f2cffa` with the documented classroom overlay.
No numerical solver changes are introduced by this release. The release tag also
records the updated repository documentation and download links; the package
manifests identify their own included file snapshots.

Archive CRCs, SHA-256 file manifests, retained source and manual links were checked.
The retained integration source is documented by each package manifest. The
PowerPoint files and their download links were removed from this distribution;
platform guidance and source-integrity metadata were updated accordingly.
The numerical/plugin sources are unchanged. The Windows installer was rebuilt to remove the instructor PowerPoint from its embedded corresponding-source archive; its runtime and installer control code remain unchanged.

Windows x64 runtime/bridge checks passed in an isolated environment. Interactive
student Rhino UI and installation on a second Windows PC remain unverified.
Mac packages require **macOS 15+, Rhino 8 and native Python 3.13**. Both native
wheel sets were resolved and checked; launcher syntax and wrong-architecture
preflight were checked. **Native Rhino/Mac acceptance remains pending.** Rosetta,
Linux, Windows ARM and older macOS do not have a verified installer in this release.
Use CPU backends for the introductory plate and roof exercises.

This is an educational experimental alpha, not engineering qualification or a
claim that every hardware and operating-system combination has been tested.
