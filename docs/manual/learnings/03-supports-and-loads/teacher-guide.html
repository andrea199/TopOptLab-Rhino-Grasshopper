TOP OPT LAB / LESSON 03 / 20 MINUTES

TEACHER GUIDE

Add supports and loads.

Select actual grid nodes, constrain the left edge and apply one total downward force of 100 N.

Prepare before class

  • Open the exact lesson files before class; check plugin loading, geometry, units and preview.
  • For calculation lessons, test Run, Stop, Reset and save/reopen on the actual classroom installation. Native archive checks and Python reference solves do not replace this interactive acceptance.
  • Keep the wired solution and reference table available. Where a student cannot calculate, use paired work or supplied evidence and label its provenance.
  • Introduce only the new concepts for this block. Keep the component reference available for detailed port questions.

Demonstration recipe

  1. Continue your saved lesson 02 definition, or open the partly wired starter. Open the shared Rhino model in millimetres and keep h = 6 mm.
  2. Right-click Fixed edge → Set one Curve; select the vertical curve on layer 02_Fixed_edge. Right-click Load point → Set one Point; select the point on 03_Load_point.
  3. Add TopOpt Support and TopOpt Load if continuing your own file. In the supplied starter they are already placed. Feed Domain / D to the D input of both.
  4. Connect Fixed edge to Support / Selection (G). Connect Load point to Load / Selection (G). These two selection wires are deliberately absent in the starter.
  5. Keep Support Fix X and Fix Y true. These are translations along the domain plane axes; World XY is used here.
  6. Use the supplied vector parameter (0, -100, 0). Connect it to Load / Total force (F). In a file built by hand, right-click a Vector parameter → Set one Vector, or construct XYZ with X = 0, Y = -100, Z = 0.
  7. Inspect Support / Nodes and Load / Nodes in Rhino. Add native Point parameters as viewers if needed. Confirm the left edge and the midpoint of the right edge.
  8. Read the messages: Support selects 11 nodes; Load selects 1 node. The force is TOTAL, not 100 N per selected node.
  9. Hide the illustrative arrow layer if it causes confusion. The reference arrow is not a numerical load. Save the file for lesson 04.

Questions, errors and recovery

ObservationResponse
No selected nodesCheck the selected Rhino layer and the Domain D wire. Do not select the reference arrow.
Unexpected nodesRead the Nodes outputs. Point selection snaps to the nearest active node within 0.76h; curve selection includes active nodes within that distance.
Wrong force magnitudeInspect the vector value; the default Load force is not the 100 N classroom value.
Support freezes the plate?Only selected node translations are constrained. The rest of the plate can deform.

Expected checkpoint

  • h = 6 mm; 200 active cells.
  • Left-edge support: 11 nodes, both X and Y fixed.
  • Right midpoint load: 1 node, total force (0, -100, 0) N.
  • You can distinguish the geometry selection, snapped nodes and applied force.

Conceptual scope

The cell grid and selected nodes are the numerical model. At h = 6 mm, node spacing is 6 mm. The edge at x = 0 selects 11 corner nodes; the point (120, 30, 0) lies exactly on one node. These counts are specific to this geometry and grid.

No physical response is calculated in this block. An empty force preview is a selection or display question to investigate before moving on.
