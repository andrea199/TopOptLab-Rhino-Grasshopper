Teacher guide

Block 01 ·15 minutes · Students know Rhino; Grasshopper and FEM are new.

Prepare before class

  1. Complete software installation before the lesson. This block’s starter uses native Grasshopper parameters; later blocks need TopOptLab.
  2. Open the Rhino model. Confirm millimetres, select World Top and use Zoom Extents.
  3. Open the Grasshopper starter. There should be three empty geometry parameters and four instruction panels. No TopOpt solver is present.
  4. Arrange Rhino and Grasshopper side by side. Check that layer names, point and force arrow are visible. Save a separate teaching copy.
  5. Open slides.html locally. Keep this guide on a second screen or print it.

The Rhino arrow is drawn on layer 04_Reference_arrow_NOT_a_load. Its length is illustrative. It is not a force object and must never be selected as the Boundary or Fixed edge.

Seven steps, one learning goal

SLIDE1 / 0–2 min

Predict before you calculate.

Ask: What do you expect?

Do: Students predict movement before seeing results.

Expected answer: Likely downward displacement near the loaded end; no numerical magnitude is expected.

Ask students to sketch the likely direction of movement. Do not show a computed deformation yet. Expect an overall downward response near the loaded end. Treat the sketch as a qualitative prediction, not a numerical result.

SLIDE2 / 2–5 min

Read the problem.

Ask: What defines the problem?

Do: Point to the outline, left edge and arrow.

Expected answer: Geometry, support and load are three different inputs.

Use the diagram to identify three different modelling inputs. Boundary is an available area, support is a movement restriction, and load is an applied action. Ask a student to describe the problem without naming any software command.

SLIDE3 / 5–7 min

Choose a model.

Ask: What are we assuming?

Do: Describe a flat plate of constant thickness.

Expected answer: A2D, small-deformation, linear-elastic idealisation, with later material input.

Explain that this is a plane-stress plate model with constant thickness. The first block needs no material parameters yet; we will choose those consistently before FEM. It does not include out-of-plane bending or buckling. Avoid presenting this as a full design check.

SLIDE4 / 7–9 min

What is allowed to move?

Ask: Does fixed mean nothing moves?

Do: Ask which parts of the model are constrained.

Expected answer: Only the selected left-edge nodes are constrained in X/Y; the remaining nodes can move in plane.

Fixing X and Y along the complete left edge is the idealised clamp for this 2D continuum model. Right-edge and internal nodes remain free in plane. There is no separate nodal rotation input in the 2D Q4 continuum element. Ask what would happen if the support were removed: rigid-body motion makes the static problem ill-posed.

SLIDE5 / 9–11 min

Describe the force.

Ask: Where versus which direction?

Do: Compare the point coordinates and force vector.

Expected answer: Location in mm; force in N. The nonzero component is negative Y.

Check the World XY axes in Top view. Explain location versus vector: (120,30,0)mm says where; (0,-100,0)N says direction and total magnitude. The arrow’s drawing length is illustrative. A point force can produce mesh-sensitive local stress; this becomes a later discussion.

SLIDE6 / 11–13 min

Find your way around the canvas.

Ask: What is a wire?

Do: Find a parameter, a component image and the port sides.

Expected answer: Parameters store data; components transform it; wires connect compatible data.

Demonstrate opening Grasshopper, zooming and panning, selecting a parameter and reading its tooltip. Point to input-left/output-right on the Domain image. Do not ask beginners to reproduce a full solver workflow. If time allows, right-click Boundary and use Set one Curve with the Rhino boundary layer visible.

SLIDE7 / 13–15 min

Explain the model before solving it.

Ask: Can you explain the model?

Do: Students answer the sheet and locate the three starter parameters.

Expected answer: Identify fixed edge, downward force and a plausible deformation sketch before grid creation.

Open files/lesson01_cantilever_mm.3dm, choose World Top and Zoom Extents. Open files/lesson01_starter.gh. The three geometry parameters intentionally start empty: they are selections to make in the next block. Orange missing-data warnings before selection are expected. Stop here when students can explain geometry, support and load and draw a plausible direction of deformation.

Optional selection demonstration

  1. In Rhino, hide all layers except01_Boundary. In Grasshopper, right-click Boundary → Set one Curve. Select the closed rectangle.
  2. Show only02_Fixed_edge. Right-click Fixed edge → Set one Curve. Select the left vertical line.
  3. Show only03_Load_point. Right-click Load point → Set one Point. Select the point at (120,30,0).
  4. Show the remaining layers again. Explain that these selections are geometry references; TopOpt support and load objects will be constructed later.

Common misunderstandings

Student statementUseful correction
The arrow is the force input.It illustrates direction. A later TopOpt Load component receives a geometric selection and a numerical vector.
The outline is already a mesh.It is a curve. Domain will turn it into the solver’s cells.
Orange means the file is broken.An empty parameter can warn that no geometry has been selected yet. Read its message before proceeding.
A fixed support freezes the plate.It constrains only the selected nodes; the rest of the plate deforms.

Ready to move on?

Ask students to point to the three inputs and explain one modelling assumption. Next: add Domain, choose h=5mm and inspect the grid before setting supports or running FEM.

No computed displacement, stress map or optimised shape is introduced in this first block.
