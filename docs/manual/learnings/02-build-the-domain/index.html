Build it step by step

  1. Open the Rhino model from lesson 01. Use World Top view and millimetres.
  2. Open lesson02_starter.gh. Right-click Boundary → Set one Curve. Select only the closed outline on layer 01_Boundary.
  3. Double-click the canvas and search for TopOpt Domain, or find it in TopOptLab → 1 Geometry.
  4. Connect the Boundary parameter output to Boundary / B, the top-left input.
  5. The starter has an integer Cell size slider, range 3–12, set to 6. Connect it to Cell size / h, the fourth input. Use exact values 12, 6 and 3 for the experiment.
  6. Leave Holes / H and Keep / K unconnected. Leave Plane / P at its World XY default. Thickness is not an input to Domain.
  7. Enable Domain preview. In Rhino, use shaded display with mesh wires visible. If other geometry obscures the cells, turn its preview off. Read the cell count in the message below Domain.
  8. Try h = 12, 6 and 3. Record each cell count, then return to h = 6 and save your work for lesson 03.

What does discretisation mean?

The boundary describes the continuous design area. TopOpt Domain tests cell centres against that area and outputs the active cells. For this aligned rectangle, all cells fit exactly. With curved outlines or holes, the grid approximates the boundary: a retained square can extend outside the original curve.

Cells are the small regions used by the numerical model; nodes are their corner points. A finer grid creates more cells and nodes. It usually takes more computation, but does not repair incorrect loads, supports or assumptions.

Set h before worrying about a red component. The default 0.25 would request 480 × 240 = 115,200 cells here, above the component’s 60,000-cell limit. Use 6 mm. Do not confuse h with the plate thickness of 2 mm.

End-of-block checkpoint

  • One closed 120 × 60 mm boundary is connected to B.
  • The Cell size slider is connected to h and restored to 6 mm.
  • Domain reports 200 cells | 0 kept; the grid has 20 columns and 10 rows.
  • You can explain why halving h produces four times as many cells in this example.
