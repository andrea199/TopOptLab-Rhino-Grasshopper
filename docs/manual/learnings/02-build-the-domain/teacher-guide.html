TOP OPT LAB / LESSON 02 / 20 MINUTES

TEACHER GUIDE / 20 MINUTES

Make the grid visible.

Alternate explanation and student action. Introduce only Boundary and Cell size; postpone material, loads and optimisation.

Prepare before class

  • Confirm that TopOpt Domain loads on the classroom installation. This block creates geometry locally; it does not call the Python solver.
  • Open the shared lesson 01 Rhino model. Check millimetres, World Top and the closed outline on 01_Boundary.
  • Open the wired solution, select the boundary and confirm the 200-cell message at h = 6. Check that the mesh wires are visible.
  • Keep the starter and solution ready. Grasshopper archive readback checks do not replace this classroom preview check.

Teaching script

TimeExplain / demonstrateStudent action / evidence
0–2 minAsk: “Can a computer calculate directly on an outline?” Recall the design area.Identify the boundary; predict what a grid adds.
2–5 minShow the 6 mm grid. Distinguish cells and corner nodes. Explain the centre-in-region rule.Point to one cell and one node. State that the grid is a representation.
5–10 minShow Boundary → B and slider → h. Explain the left-to-right data flow. Keep H/K empty and P at World XY.Make the two wires, select the outline, obtain 200 cells.
10–15 minAsk students to predict counts before trying 12 and 3 mm.Record 50, 200, 800. Explain the fourfold change when h halves.
15–18 minAsk: “Does a finer grid make a wrong support correct?” Explain resolution versus modelling assumptions.Write one benefit and one cost of refinement.
18–20 minUse the checkpoint. Tell students to restore 6 mm and save.Show 200 cells, 0 kept; ready for the next lesson.

Demonstration recipe

  1. Open the Rhino model from lesson 01. Use World Top view and millimetres.
  2. Open lesson02_starter.gh. Right-click Boundary → Set one Curve. Select only the closed outline on layer 01_Boundary.
  3. Double-click the canvas and search for TopOpt Domain, or find it in TopOptLab → 1 Geometry.
  4. Connect the Boundary parameter output to Boundary / B, the top-left input.
  5. The starter has an integer Cell size slider, range 3–12, set to 6. Connect it to Cell size / h, the fourth input. Use exact values 12, 6 and 3 for the experiment.
  6. Leave Holes / H and Keep / K unconnected. Leave Plane / P at its World XY default. Thickness is not an input to Domain.
  7. Enable Domain preview. In Rhino, use shaded display with mesh wires visible. If other geometry obscures the cells, turn its preview off. Read the cell count in the message below Domain.
  8. Try h = 12, 6 and 3. Record each cell count, then return to h = 6 and save your work for lesson 03.

Expected observations

12 mm: 10 × 5 = 50 cells. 6 mm: 20 × 10 = 200 cells. 3 mm: 40 × 20 = 800 cells. No preserve regions are connected, so kept = 0. For these exact divisions, cell area sums to 7,200 mm².

The number of unique grid-corner positions is (nx + 1)(ny + 1): 66, 231 and 861. The preview mesh stores separate vertices per face; counting raw mesh vertices is not a reliable way to count unique FEM nodes.

Common problems

ObservationCheck
Boundary parameter is orangeSet one Curve from 01_Boundary. The starter intentionally contains no geometry.
Too many cells / red DomainConnect the slider to the fourth input h. Set 6; the default 0.25 is too fine for this plate.
Open or non-planar boundary errorSelect the closed outline, not the fixed edge or reference arrow. All region curves must lie in World XY.
Solid patch, no grid linesEnable Domain preview and mesh wires in the Rhino display mode. Read the component message independently of the visual style.
Counts differCheck the 120 × 60 dimensions, millimetres, one boundary, H/K empty and exact h values.
Domain is missingCheck TopOptLab installation before class; use the browser schematic for the concept and pair the student with a prepared workstation.

One sentence to retain

“Cell size controls the resolution of our model; it does not define the material, thickness or loading.”
