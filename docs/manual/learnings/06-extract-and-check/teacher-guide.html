TOP OPT LAB / LESSON 06 / 25 MINUTES

TEACHER GUIDE

Extract and check the shape.

Convert densities into a binary cell shape, run a new FEM solve and compare it against the matching baseline.

Prepare before class

  • Open the exact lesson files before class; check plugin loading, geometry, units and preview.
  • For calculation lessons, test Run, Stop, Reset and save/reopen on the actual classroom installation. Native archive checks and Python reference solves do not replace this interactive acceptance.
  • Keep the wired solution and reference table available. Where a student cannot calculate, use paired work or supplied evidence and label its provenance.
  • Introduce only the new concepts for this block. Keep the component reference available for detailed port questions.

Demonstration recipe

  1. Continue lesson 05 or open the starter. Select the shared Rhino geometry, then run BASELINE and OPTIMISATION in that order if the file has no current results.
  2. Keep the same physical model. In Settings, Threshold = 0.40; connect that same value to the optimisation Results T input. Use Scale = 0 to inspect the candidate without display distortion.
  3. Read Results Shape M. It retains cells whose density is at least 0.40. This mesh is not a new structural analysis.
  4. Trace the third Engineering component labelled VERIFICATION. D, S, Cases, M and O match the earlier stages; Mode = 2.
  5. Connect the completed OPTIMISATION Result R → VERIFICATION Source. This is the missing wire in the starter. Source expects engineering result data, not the mesh from Shape M.
  6. Pulse RUN VERIFICATION after optimisation completes. Wait for a completed binary-grid reanalysis. Read errors rather than forcing a disconnected candidate through.
  7. Connect the verified result to FEM Results and inspect displacement and stress. The binary candidate uses full material in retained cells; it is not smoothed or remeshed.
  8. Compare Results receives BASELINE Result R as Baseline and VERIFICATION Result R as Candidate. Read its mass saving and displacement comparison. Matching inputs and completed results are required.
  9. Reference at T = 0.40: mass 0.0542592 kg, maximum displacement about 0.0186599 mm, maximum von Mises about 20.3149 MPa. It is 52% lighter than the full plate; its mass differs from the 40%-density design.
  10. Optional challenge after recording the reference: set the shared threshold to 0.50 and run VERIFICATION again. The supplied reference design produces disconnected pieces and is rejected. Record this as a modelling observation, then restore 0.40 and rerun verification.
  11. Save the model and report locations. If baking Shape M, use an explicit Bake pulse, label the Rhino geometry as a thresholded candidate and test Undo. Bake does not validate the structure.

Expected checkpoint

  • Threshold = 0.40 for the guided run; no smoothing/remeshing.
  • Mode 2 Source is the completed Engineering optimisation result.
  • Verified binary mass and displacement are recorded separately from density metrics.
  • A rejected disconnected candidate is recognised as a useful result, not hidden.

Conceptual scope

The phrase final verification here means full-material FEM on the retained binary grid. It does not mean verification of a smooth CAD redesign, a manufactured specimen or a structural system. A later geometry edit would require its own model and analysis.

For a refinement study, hold the physical shape and loads fixed. Rerunning optimisation on a finer grid changes the design as well as the discretisation. Point-load and sharp-corner peak stresses need particular care.
