TOP OPT LAB / LESSON 08 / 10 MINUTES

TEACHER GUIDE

Discuss the results.

Present a concise comparison, distinguish observed results from reference values and propose a justified next check.

Prepare before class

  • Open the exact lesson files before class; check plugin loading, geometry, units and preview.
  • For calculation lessons, test Run, Stop, Reset and save/reopen on the actual classroom installation. Native archive checks and Python reference solves do not replace this interactive acceptance.
  • Keep the wired solution and reference table available. Where a student cannot calculate, use paired work or supplied evidence and label its provenance.
  • Introduce only the new concepts for this block. Keep the component reference available for detailed port questions.

Demonstration recipe

  1. Open your saved model and worksheet notes. Use the small plate comparison as the common minimum; add the roof observations if you completed them.
  2. Choose the full-material baseline and the verified binary candidate from the same physical model. Do not compare an unrelated job or relaxed design stress as though it were binary FEM stress.
  3. Record geometry, units, material, h, thickness, applied force, threshold and which stages you actually ran. If you used reference values, label them explicitly.
  4. Present mass and maximum displacement for both stages, plus termination and verification status. Use matching field units, legend maximum and deformation scale for visual comparisons.
  5. Explain one difference between your lesson 01 prediction and the calculated response. A changed understanding is a useful outcome.
  6. State one unresolved modelling issue and one concrete next check. Examples: loading/support patches, fixed-shape refinement, out-of-plane stability or a connection model.
  7. Save your Grasshopper definition, the completed worksheet or PDF, and your observation table. Keep the runtime job folder if you need case selection and report access later.
  8. Give a 30-second evidence-based conclusion to your partner. End with what you would investigate next, rather than declaring the part universally safe.

Expected checkpoint

  • Comparison uses matching baseline and verified candidate.
  • Numbers include units and provenance (own run or supplied reference).
  • The conclusion contains evidence, one limitation and one next action.
  • Saved files and notes make the work understandable to another person.

Conceptual scope

Suggested minimum submission: saved Grasshopper definition; completed worksheet/PDF; a baseline-versus-verified comparison with units; and a four-sentence conclusion. Keep reference files unchanged and save personal work under a new name.

Assessment: model and units (5 points), correct stages and numerical evidence (5), controlled comparison and interpretation (5), limitations and reproducible communication (5). Do not grade visual smoothness as proof of accuracy.
