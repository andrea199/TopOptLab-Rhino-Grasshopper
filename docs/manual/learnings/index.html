STEP BY STEP / THREE-HOUR COURSE

The learning path.

Start with a prediction. Build a model, solve it, then check what the result means. Every lesson connects back to the component reference.

The course includes 170 minutes of teaching and exercises, with a 10-minute break after lesson 04. All eight lessons are available, with slides, teacher guides, student worksheets and linked practice files. Start with lesson 01 and continue in order.

Install from Rhino Package Manager

Run _PackageManager → Online → enable Include pre-releases → search topoptlab-rhino → select the version for your platform → Install. Restart Rhino, then right-click a TopOptLab component and open the Python setup folder. Run SETUP-PYTHON.cmd on Windows or SETUP-PYTHON.command on Mac.
