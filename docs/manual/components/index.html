Before you begin

Inputs enter on the left; outputs leave on the right. Drag between ports to create a wire. Hold Shift to add another source to an occupied input. A slider provides a number; a Toggle keeps a Boolean state; a Button provides a brief pulse.

Declare consistent geometry, force and material units. Density is a design variable, displacement is a physical response, and preview deformation scaling changes only the display. Compare independent load cases separately. A converged optimisation is not the same as a verified final shape.

The plugin’s numerical stages are distinct: baseline FEM → optimisation → verification. 3D surface extraction and conforming final FEM introduce additional stages. Follow the matching example and inspect its reports.
