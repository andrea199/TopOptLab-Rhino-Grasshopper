Prepare once.
Learn in sequence.

This manual opens directly in a browser and works offline. Keep the manual folder intact so images, examples and lesson files stay connected.

For the first lesson

  1. Use Rhino 8 with a working license and Grasshopper.
  2. Open the Rhino model and Grasshopper starter from the lesson page. The starter contains native parameters and instructions.
  3. Use the slides for the explanation, the teacher guide for timing and the student sheet for predictions.
Open lesson 01

For the later FEM and optimisation blocks

Install the complete TopOptLab project before class. The Grasshopper plugin uses an external Python worker: the environment and worker must remain in their configured location.

Windows / Rhino 8

The source installer currently supports Windows x64 and Python 3.13. Save and close Rhino, then run INSTALL.cmd from the complete project checkout.

For the course, use the complete Windows ZIP linked below. It contains software/windows/TopOptLab-Students-Windows-0.4.0-Setup.exe and its CPU Python runtime. The source-installation route above is an alternative for developers and requires Python 3.13 and internet access.

Mac / experimental Yak alpha

Not yet tested inside Rhino or Grasshopper for Mac. CPU-worker tests pass on Apple Silicon and Intel. Requires macOS 15+, Rhino 8 SR37+ and native Python 3.13.

Run _PackageManager, enable Include pre-releases and install topoptlab-rhino 0.4.0-alpha.5. After restart, open the component Python setup folder and run SETUP-PYTHON.command. See Mac experimental status and outstanding checks.

Install from Rhino Package Manager

Run _PackageManager → Online → enable Include pre-releases → search topoptlab-rhino → select the version for your platform → Install. Restart Rhino, then right-click a TopOptLab component and open the Python setup folder. Run SETUP-PYTHON.cmd on Windows or SETUP-PYTHON.command on Mac.

Teacher checklist

  • Open the exact lesson file before class.
  • Check units, Top view, layer visibility and geometry selection.
  • For calculation lessons, test Run, Stop, Reset, reports and preview on the classroom installation.
  • Check save/reopen and Bake/Undo before using those operations in class.

Experimental Mac Yak alpha: Apple Silicon and Intel

A single experimental Mac package is published for native arm64 and x86_64 Python. It requires macOS 15+, Rhino 8 SR37+ and native Python 3.13. It has not been tested inside Rhino or Grasshopper for Mac. Install via Package Manager, Online, Include pre-releases, topoptlab-rhino 0.4.0-alpha.5.

The CPU worker, dependency setup, runtime reuse and host memory/path checks pass on both native Mac architectures. Each architecture passed 263 integration tests, with 11 expected CUDA/Windows test exclusions. Loading all components and using the menus, Rhino geometry, preview, Run/Stop/Reset, save/reopen and Bake/Undo inside Rhino for Mac remain pending.

For experimental installation, use the Mac package README and SETUP-PYTHON.command. Keep the source folder intact: it contains this same manual and all examples. Do not use the Windows .cmd launcher or Rosetta Python on a Mac.

Source and publication

The manual is maintained inside docs/manual/ in the TopOptLab-Rhino repository. Internal navigation uses relative links so the same manual can be viewed locally or hosted. The repository is public. Use Rhino Package Manager for the current Windows release or experimental Mac alpha. Historical course ZIPs remain a separate draft; they are not the current public download route.
