CPU setting for the shelf bracket

The shelf example starts with CUDA selected and 2.5 mm cells. With the supplied CPU installer, explicitly select Backend 2, CPU AMG before Run. This model is more demanding than the introductory exercises. Its fine-grid voxel reanalysis is available, while the final CAD-surface FEM remains incomplete. A preliminary exported shape does not establish complete final verification.

Calculation sequence

  1. Keep the same Domain, Supports, Load Cases, Material and Settings connected to the three Engineering stages.
  2. Run the baseline, then optimisation, waiting for completion.
  3. Connect completed Optimisation R to Verification Source and run verification.
  4. Use FEM Results for the baseline and verification. Use Results for optimisation. Compare completed stages with matching physical inputs.

Roof-rib classroom model

The roof adds the 21st prepared definition. Its geometry is internalised in the GH file. The separate Rhino model is included for viewing the physical outline.

Open roof GHReadable roof GHXRhino geometryLesson 07

The five independent cases are SLS uniform snow, ULS uniform snow, ULS left snow, ULS right snow and ULS wind uplift. Each case contains six point loads and self-weight acting simultaneously.

Run the three stages in order. Review Stage changes visibility only. Case selects a saved response after completion. Field 1 shows displacement; Field 2 shows stress, with relaxed design stress during optimisation. Keep the generated job folders in place for saved-case selection.

Lesson 07 includes the reference comparison tables and the source numerical reference. Supplied values are teaching references for the declared model. The full project also retains the original reports in its roof teaching folder.

Progressive lesson files

The introductory course adds 11 progressive definitions: one Lesson 01 starter and a starter/solution pair for Lessons 02–06. These are steps in the same small plate exercise, rather than 11 additional physical studies. Lessons 07 and 08 use the prepared roof model and the collected results.

  4. Lesson 04: Run the first FEM analysis.
  5. Lesson 05: Optimise the structure.
  6. Lesson 06: Extract and check the shape.
  7. Lesson 07: Apply the workflow to the roof rib.
  8. Lesson 08: Discuss the results.
