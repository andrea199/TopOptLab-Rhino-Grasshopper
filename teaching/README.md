# Teaching materials

a three-hour class covering assumptions, actions, supports, baseline FEM,
topology optimization, threshold reanalysis and mesh sensitivity.

The original presentation and detailed speaker notes are in **Italian**.
The software interface and the repository guides are in **English**; the English
instructor/student guides accompany the original deck rather than translating it.
Download the full repository so relative paths to figures and reference reports work.

For shorter exercises, use the [20-example gallery](../docs/EXAMPLES.md).
